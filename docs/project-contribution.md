# Individual Portfolio Contribution

## Context

This repository represents an individual portfolio view of a **six-member academic project**. It is not presented as an independent rewrite of the team's implementation.

## Contribution Framing

My portfolio focus is on understanding and communicating the system-level engineering involved in the project, particularly the intersection of:

- real-time computer vision;
- Python software architecture;
- face recognition and tracking;
- serial communication;
- Arduino-based embedded response;
- hardware/software integration.

## Engineering Skills Demonstrated

### System-level thinking

Breaking a security application into sensing, inference, decision, communication, and physical-response stages.

### Embedded integration

Understanding how a host-side software decision can be converted into a deterministic microcontroller-controlled output.

### Real-time software concepts

Understanding frame processing, worker-based recognition, queues, tracking, and temporal decision making.

### Security-oriented design

Considering the difference between known and unknown identities, event handling, false decisions, privacy, and deployment limitations.

## What This Repository Does Not Claim

The original project was collaborative. This portfolio repository therefore does **not** claim sole authorship of the complete system or its source code.

The complete group implementation, private datasets, and personal identity information are intentionally excluded.

## Portfolio Positioning

This project complements my other engineering work in digital design, Verilog/RTL, embedded systems, and computer architecture. It demonstrates experience moving between software, algorithms, communication interfaces, and physical hardware rather than focusing on only one layer.
