# Results & Evaluation

The original academic project demonstrated the integrated operation of the computer-vision recognition pipeline and embedded alert path.

For a public portfolio repository, quantitative results should only be added when they are supported by actual project measurements.

## Suggested Evaluation Metrics

| Metric | Purpose |
|---|---|
| Recognition accuracy | Overall identification quality |
| False acceptance rate | Measures incorrect known-person matches |
| False rejection rate | Measures missed known identities |
| Unknown detection rate | Measures detection of unregistered people |
| End-to-end latency | Measures response time from observation to alert |
| Processing rate | Measures real-time throughput |
| Alert response time | Measures software-to-buzzer delay |

No fabricated numerical performance claims are included in this repository.
